| 01-agent-configuration.png | 智能体名称、简介、角色任务和已有 API 服务 |
| 02-intent-definition.png | 新增意图窗口 |
| 03-workflow-start.png | 意图设计画布与开始 rawQuery |
| 04-node-types.png | 可添加的节点类型 |
| 05-model-configuration.png | 大模型调用输入与提示词配置界面 |
| 06-model-output.png | 大模型 output 为 string，平台 errorMsg 为 string |
| 07-code-template.png | 执行代码块原模板与示例参数 |
| 08-code-entrypoint.png | 原模板入口 function main(params) |
| 09-earlier-code-test-error.png | 较早的代码执行异常，无详细根因 |
| 10-parser-output-fields.png | 用户反馈可用后的解析输出字段列表 |
| 11-condition-settings.png | 条件判断配置面板 |
